# Sadegan Accounting System

Sadegan Accounting System is a bilingual (Persian / English) accounting software developed since **2006**.

## Overview

Sadegan is a financial and accounting system with a strong focus on the **gold and jewelry industry**, especially workflows related to **jewelry design and production**.

Although it is optimized for this specialized domain, it can also be used as a **general-purpose accounting system** for standard business and financial operations.

## Features

- Bilingual interface (Persian / English)
- Specialized support for gold and jewelry production workflows
- Suitable for general accounting use
- Flexible structure for production-based accounting systems

## Source Code & Releases Policy

This repository does not contain the source code of the software.

Sadegan Accounting System is a **commercial, server-side application**, and the core logic and backend are fully hosted and executed on the server.

All releases available in this repository include only the **desktop client (UI layer)**, which contains no sensitive business logic or proprietary source code.

The desktop client is strictly a **lightweight interface** for interacting with the server-side system.
